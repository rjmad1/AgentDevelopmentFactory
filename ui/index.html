🏛️ Architecture & Zero-Cost Philosophy

Agent Development Factory (ADF) is a spec-driven multi-agent assembly platform. Every agent begins as a verified contract with deterministic behavioral constraints before any code runs.

  • Zero-Dollar Spending Ceiling: The platform operates with a strict $0.00 USD invariant—zero proprietary API tokens or cloud subscriptions required.
  • Local SLM Orchestration: Powered by local models (Ollama Qwen 2.5, Llama 3.2) or deterministic rule-based engines.
  • Pure Node.js Runtime: Zero external npm runtime dependencies (dependencies: {}) for maximum auditability and zero supply-chain risk.
  • Air-Gapped Ready: Complete offline operation with zero data exfiltration or external telemetry calls.

🛡️ 4 Defense-in-Depth Guardrails

Multi-layered security boundaries filter threats before, during, and after agent tool execution:

1. Input Rail: Sanitizes prompts, strips jailbreak attempts, blocks prompt injection, and scrubs PII/PHI.
2. Dialog Rail: Enforces domain-specific scope, detects topic drift, and restricts prohibited actions.
3. Execution Sandbox: Strict real filesystem path containment; prevents directory traversal and unauthorized shell commands.
4. Output Rail: Validates structured schema contracts, prevents credential leaks, and checks for hallucinated citations.
